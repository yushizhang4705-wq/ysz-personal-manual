# ysz-personal-manual：给 AI 办入职的「个人说明书」采访器

> **别再对着空白框憋提示词了。让 AI 反过来当人事顾问，一次问你 2 个大白话问题，聊 20 分钟语音，自动生成所有 AI 通用的《个人说明书》。**

很多人用了大半年 AI，每次开新窗口还是像第一天认识它：
- 想写个「自定义指令（Custom Instructions）」或 `CLAUDE.md`，对着空白框脑子一片空白；
- 去网上抄了一堆「你是顶级专家」模板，结果写出来的东西还是一股「不是 A 而是 B、三段排比、总之赋能」的塑料味；
- 把几万字资料全塞进提示词，结果上下文越滚越大，AI 反而变笨、忘掉最重要的规矩。

这个项目把我在实战里验证过的 **「反客为主采访法 + 60 行薄常驻记忆架构」** 完整开源出来。无论你是只用手机豆包 / DeepSeek / ChatGPT 的普通人，还是同时用 Claude Code、Codex、Devin 的重度玩家，都可以直接拿去用。

---

## 这套采访流程有什么不一样？

1. **先读旧底稿，不问废话**：如果你已经有零散笔记，AI 会先读一遍，写清楚的不重问，只问「我理解的是……对吗？」。
2. **8 项通用底座 + 3 套身份选装包**：不管你是**自媒体创作者**、**职场打工人**还是**独立开发者**，第 1 问自动匹配你的身份题库；全程一次只问 2 道大白话问题，躺着发语音就能答完。
3. **A/B/C 样句盲测 + 结构黑名单**：不让你抽象形容「我喜欢什么文风」，AI 现场写 3 句不同语气的话让你盲选，从句式结构上砍掉 AI 腔。
4. **专抓前后矛盾 + 老毛病监督**：只用你的原话（加引号），AI 推断必须标「推断」；还会专门问出你的「老毛病」（比如拖延、沉迷搭系统不发内容），约定好以后怎么拿数据怼醒你。
5. **一鱼四吃分层输出**：
   - **A. 《个人说明书》完整版**（12 项完整档案，按需读取不占上下文）
   - **B. `USER.md` 高频常驻摘要**（硬锁 60 行以内，每轮对话必用）
   - **C. 隐私绝不公开红线清单**
   - **D. 300 字手机/网页端浓缩卡**（直接粘贴进豆包 / DeepSeek / ChatGPT 设置）

## 用法一：零代码小白版（直接复制这段话发给任何 AI）

不需要安装任何软件。打开你常用的 **ChatGPT / Claude / DeepSeek / 豆包 / Kimi**，新建一个对话，把下面这段话完整复制发给它：

```text
你是我的 AI 协作顾问。请通过采访我，帮我产出一份能被所有 AI 助手读取的《个人说明书》。

【采访规则】
1. 一次只问我 2 个问题，用大白话问，我答完你再问下一组，绝不要一次甩出一长串问卷。
2. 我可以用语音回答，错别字和口误你自动忽略。请先提醒我不要透露密码、证件号或具体敏感财务数字。
3. 每项最多追问 2 次。当我回答模糊（比如“我喜欢简洁”）时，追问我一个最近的真实例子。
4. 当我说“不知道/没想到”时，立即给我 3 个具体的典型选项（A/B/C）让我挑。
5. 如果我前后说法矛盾，请直接客观指出来，不要附和我。我说“跳过”就跳过并记为「待补充」。

【按顺序采访我这 12 项】
1. 个人定位与能力边界：让别人用一句大白话介绍我是干嘛的？哪些事我自己擅长，哪些事全靠 AI 替我做？
（请根据我第 1 项的回答，自动按“内容创作者 / 职场打工人 / 开发者”调整第 2–5 项的问法）
2. 当前核心业务与投入时间：我目前在做的事做到哪一步了？本月最重要的 1–3 件事是什么？
3. 服务对象与真实痛点：举一个真实的人（客户、观众、老板或同事），他具体卡在哪一步？
4. 交付与合规边界：哪些事我接、哪些不接？做到哪一步算完？有哪些脱敏红线？
5. 高频 AI 任务 Top 3：我最常让 AI 帮我产出哪三类东西？每类我最满意的交付格式长什么样？
6. 表达风格盲测（重要）：请针对我常写的内容，现场写 A、B、C 三句不同语气的样句让我盲选哪句像我、哪句不像；再和我确认一份「反 AI 味禁用清单」（如禁用三段排比、破折号、总结升华、特定口头禅）。我也可以贴 2–3 条我以前写的话给你提取风格。
7. 隐私红线：哪些类别的信息绝对不能出现在公开内容里？哪些不能写进记忆库？
8. 自主权与协作边界：什么事 AI 直接做不用问，什么事不先问过我直接做会让我火大？
9. 决策偏好：需要做决定时，给我几个选项合适？我拍板时最看重数据、审美、直觉、成本还是速度？
10. 最烦的 AI 毛病：啰嗦、空夸附和、假完成（没验证说做完）、擅自越界、满屏表格加粗，我最烦哪一两个？
11. 阅读习惯与信息密度：我平时在手机还是电脑上看回复？多长算太长？表格、列表、链接、专业术语要怎么处理？
12. 老毛病与纠偏方式：我心里最信奉哪条原则？我自己知道的坏习惯（如拖延、沉迷搭工具不产出、过度追求完美）是什么？当我又犯病时，你用什么方式提醒我最有效（比如直接拿数据戳我）？

【采访结束后的输出要求】
全部问完后，只用我说过的话（我的原话加引号，你的推断标「推断」，未提及写「待补充」），一次性给我输出 4 份成果：
- A. 《个人说明书》完整版（按 12 项分节，禁忌项用“请不要”条列）
- B. 10 行以内的高频常驻摘要（只放每轮对话必用的决策、雷区、信息密度、默认格式、老毛病提醒方式）
- C. 隐私不公开类别清单
- D. 300 字以内的「自定义指令浓缩版」（方便我直接复制进手机 AI App 的个人偏好设置里）
最后用 3 句话总结你现在对我的理解，并指出我前后回答里是否有矛盾需要拍板。现在请先做安全提醒，然后问我前 2 个问题。
```

## 用法二：Agent 玩家版（Claude Code / Codex / Devin / Gemini）

如果你使用本地编程或内容 Agent，可以直接用 `skills` CLI 一键安装到所有主流 Agent：

```bash
npx -y skills add yushizhang4705-wq/ysz-personal-manual -g --all
```

或者手动软链到你的通用 skills 目录：

```bash
git clone https://github.com/yushizhang4705-wq/ysz-personal-manual.git
ln -s "$PWD/ysz-personal-manual/skills/ysz-personal-manual" ~/.agents/skills/ysz-personal-manual
ln -s "$PWD/ysz-personal-manual/skills/ysz-personal-manual" ~/.claude/skills/ysz-personal-manual
```

在 Agent 会话中直接输入：
> `/ysz-personal-manual` 采访我并更新我的个人说明书

采访完成后，可用内置脚本一键把「一行指针」挂载到 Claude Code (`~/.claude/CLAUDE.md`)、Codex (`~/.codex/AGENTS.md`) 和 Gemini (`~/.gemini/GEMINI.md`)，让所有 Agent 共用同一个大脑且不浪费上下文：

```bash
# 先预览变更（不改文件）
python3 skills/ysz-personal-manual/scripts/mount_pointers.py --vault-dir ~/你的共享记忆目录 --dry-run

# 确认无误后写入（会自动备份原有配置文件）
python3 skills/ysz-personal-manual/scripts/mount_pointers.py --vault-dir ~/你的共享记忆目录
```

## 目录结构

- `skills/ysz-personal-manual/SKILL.md`：Agent 自动执行的五步采访与落盘规程
- `skills/ysz-personal-manual/references/question-packs.md`：8 项通用必问底座 + 3 套身份选装包（创作者 / 打工人 / 开发者）+ A/B/C 样句盲测规范
- `skills/ysz-personal-manual/scripts/mount_pointers.py`：多端一行指针安全挂载脚本（带时间戳自动备份）
