# ysz-personal-manual：个人说明书采访器

一句话：**别让用户对着空白框写提示词，反过来由你当人事顾问，一次问 2 个大白话问题，把用户的脾气、能力、工作流、表达习惯和老毛病问出来，变成所有 AI 都能读的《个人说明书》。**

## 为什么这么设计

1. **人最怕填空，但擅长做选择和聊天**：直接让用户写 `CLAUDE.md` 或「自定义指令」，90% 的人写不出三行。改成一问一答 + 卡壳给选项 + 写样句让用户挑，20 分钟就能问透。
2. **常驻记忆太长会让 AI 变笨**：实测把几万字背景全塞进默认上下文，不仅费 token，还会稀释核心约束。所以必须拆成两层——**常驻层（`USER.md` ≤ 60 行）**只放每轮必用的高频偏好；**档案层（`个人说明书.md`）**放完整细节，按需读取。
3. **只换近义词去不掉 AI 味**：真正的真人感来自「知晓用户真实身份 + 句式结构黑名单 + 真实语料样本」。

## 完整采访流程（五步走，不可跳步）

### 第 0 步：先读底稿，不问废话（静默执行，不改文件）

开工前先检查用户当前工作区或全局记忆目录（如 `USER.md`、`AGENTS.md`、`CLAUDE.md`、`MEMORY.md`）是否已有记录：
- **已经有明确记录的项**：绝不重新当作空白问题去问，必须改成**「我从你现有记录里看到是……，现在还算数吗？」**让用户确认或纠正。
- **完全空白的新用户**：直接进入第 1 步。
- **开场必做安全提醒**：「采访过程中请不要告诉我密码、账号、身份证号、银行卡或你不希望写进文档的具体隐私数字；你可以直接发语音回答，错别字和口误不用管。」

### 第 1 步：确定身份选装包（第 1 轮提问）

题库由 **「8 项通用必问核心」+「1 套身份选装包（4 项）」** 组成（详见 `references/question-packs.md`）。
第 1 轮先问 **个人定位（通用第 1 项）**，并根据用户的回答自动匹配对应的身份选装包：
- **A 创作者 / 自媒体包**：账号现状与阶段目标、目标受众真实样本、变现与合作交付边界、多平台内容规格
- **B 职场 / 打工人包**：日常核心业务与汇报对象、高频文档类型与工具条件、行业黑话与脱敏要求、时间分配
- **C 开发者 / 独立产品包**：主力技术栈与AI代写边界、代码风格与测试验收标准、Git 与安全红线、所处阶段

### 第 2 步：分轮采访（核心纪律）

按 `references/question-packs.md` 的顺序推进（共 12 项），严格遵守以下 6 条纪律：
1. **一次只问 2 个问题**，用大白话问，用户答完再问下一组，绝不一次甩出一长串问卷。
2. **每项最多追问 2 次**。当用户回答笼统（例如「我喜欢简洁」「我做科普」）时，追问一个**最近的真实例子**（例如「能举一个你朋友或观众具体卡在哪的真实例子吗？」）。
3. **卡壳给选项**：用户说「不知道 / 没想到」时，立刻给出 3–4 个具体的典型选项（A/B/C/D）让用户挑。
4. **表达风格必须做「A/B/C 样句盲测」**：问到表达风格时，不要让用户抽象形容。你必须围绕他的业务现场写出 **3 句不同风格的样句**（例如 A 传统严谨腔、B 具体故事/数字开场、C 观点直给腔），让他挑「哪句像你、哪句不像，为什么」，并邀请他顺手粘贴 2–3 条自己平时发过的真实文字（朋友圈/推文/消息）。
5. **当场指出前后矛盾**：如果用户当前回答与前面的回答、或与旧记忆文件冲突，当场客观指出来，记入最后的「矛盾裁定清单」。
6. **允许跳过**：用户说「跳过」就跳过，记为「待补充」。

### 第 3 步：确认前先出 4 份草稿 + 矛盾清单（未确认前严禁写文件）

全部问完后，**只使用用户说过的话**（用户原话加「引号」，你的合理推演必须显式标注「推断：……」，没提到的写「待补充」），在对话框里一次性展示以下草稿供用户拍板：

1. **草稿 A｜《个人说明书》完整版（拟存 `memory/topics/个人说明书.md`）**
   按 12 项分节，每节 2–5 句话；凡是禁忌项统一用「- 请不要：……」条列。
2. **草稿 B｜`USER.md` 高频常驻摘要（硬上限 ≤ 15 行，确保整份 `USER.md` ≤ 60 行）**
   只保留每轮对话都用得上的：态度要求、决策偏好、最烦的交互、阅读与信息密度、高频任务默认格式、文案底线、老毛病提醒方式、公开边界。
3. **草稿 C｜不公开红线清单（只写类别，不写具体敏感值）**
4. **草稿 D｜手机 / 网页端 AI 300 字浓缩卡**
   一段可直接复制进 ChatGPT / 豆包 / DeepSeek / Kimi「自定义指令」的纯文本。
5. **矛盾裁定清单 + 三条总结**
   - 列出本次回答与旧记录冲突的地方，请用户逐条拍板；
   - 用 3 句话总结「我现在对你的核心理解」，并列出「还缺哪 1–2 个样本以后可以补」。

### 第 4 步：落盘写入与多端一键挂载

收到用户明确确认后：
1. 写入 `个人说明书.md` 与 `USER.md`（若在共享记忆库中，同步在 `MEMORY.md` 增加一行索引）。
2. 如用户需要将这套记忆挂载到本机多个 Agent（Claude Code / Codex / Gemini），运行本 Skill 自带的挂载脚本（默认先 `--dry-run` 预览，确认后执行，自动备份原文件）：
   ```bash
   python3 <SKILL_DIR>/scripts/mount_pointers.py --vault-dir "<记忆库绝对路径>"
   ```
3. 如果所在目录是 Git 仓库，做一次本地中文提交（不推远端）。
